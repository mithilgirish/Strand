## What is STRAND?

STRAND is an autonomous AI platform that connects every specification, drawing, purchase order, and commissioning record into a single causal model of the project — the **Parametric Knowledge Graph (PKG)**.

Five specialised AI agents run on top of the PKG to catch specification violations, predict schedule risk, and guide field commissioning — before damage is done.

## The Five Agents

| Agent | Name | Role |
|-------|------|------|
| 1 | **The Guardian** | Specification Compliance Auditor |
| 2 | **The Scheduler** | Predictive R0 Risk Engine |
| 3 | **The Oracle** | Supply Chain Intelligence |
| 4 | **The Inspector** | Commissioning QA Copilot |
| 5 | **The Brain** | Project Knowledge Copilot |

## Key Innovations

- **Spec-DNA Chain** — cryptographic lineage tracking from contract clause to commissioning record
- **R0 Contagion Score** — epidemiological risk propagation model for construction defects
- **Parametric Verification Engine** — every submittal verified against specification constraints in seconds
